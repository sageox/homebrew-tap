# SageOx Homebrew Tap

Homebrew formulae for [SageOx](https://sageox.ai) CLI tools.

## Installation

```bash
brew tap sageox/tap
brew install ox
```

## Available Formulae

| Formula | Description |
|---------|-------------|
| `ox` | Infrastructure guidance for AI coding agents |

## Updating

```bash
brew update
brew upgrade ox
```
